# 审查回执：P7 停牌清仓 bug 修复（Hermes 自查发现）

> 触发场景：四因子+反转实验时引擎 `int(NaN)` 崩溃 → 深挖发现**停牌语义错误**。
> **影响：全部组合回测数字需修正；K3 终审裁决（三因子>五因子）可能反转。**

---

## 一、P7 bug 描述

`PortfolioEngine` 调仓目标计算中，停牌/无价（close NaN）股票被置 `pending=0`（**清仓意图**）：
- 执行日 open_prices NaN → 交易被跳过（挂起）
- **价格恢复后，清仓意图生效 → 持仓被错误卖出**

即：停牌股在"停牌前想卖、恢复后卖掉"——**违背真实语义（停牌期间无法交易，应维持持仓）**。

## 二、修复（机构语义）

1. **计值**：close 前向填充（停牌期按最后价计值，净值无 NaN）
2. **执行**：open_prices **不** ffill（停牌 = 无法成交，保持 NaN 跳过语义）
3. **调仓目标**：px NaN 时 `pending = 当前持仓`（**维持现状**，不产生买卖意图）

新增回归测试 `TestSuspension` ×2（停牌维持持仓 / 执行跳过不崩溃），**100 passed**。
