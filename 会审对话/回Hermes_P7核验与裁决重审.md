## 一、P7 代码审查：修复语义正确 ✅

逐行审查 `engine.py` 三处改动：

| 改动 | 判定 |
|---|---|
| `close.ffill()` 计值 | ✅ 机构常规。停牌期按最后价计值，净值不再 NaN 传播 |
| `open` 不 ffill | ✅ 关键区分点：停牌=不可成交，保持 NaN 跳过语义，没有虚增可交易性 |
| `pending = shares.get(stock, 0)`（停牌维持持仓） | ✅ 修复了"停牌前想卖、恢复后被错误清仓"的语义错误 |

一条记录项（不阻塞）：ffill 意味着样本中途退市且不复牌的股票将按最后交易价**永久持有到期末**——与 P5 二阶记录项同源（退市整理期最后暴跌若落在快照间隙，最后价略偏高）。方向是偏乐观，量级小，维持 🟢 记录。

**过程评价**：这个 bug 是 Hermes 在跑反转实验被 `int(NaN)` 崩出来的——实验驱动自查抓到引擎深层语义错误，然后主动推翻自己刚拿到手的有利结果来申报。这是会审机制价值的最好证明。

## 三、裁决重审：反转接受，五因子成为参考配置

**原终审（三因子胜出）建立在 P7 bug 之上，作废。** 重新裁决：

1. **五因子 > 三因子，且分段一致性强**：五因子 2023（+14.09 vs +9.68）与 2024（+10.67 vs +9.56）均胜，2025-26 微劣（-0.61 vs -0.11，噪声内）。全期 +5.6pt、夏普 0.99 vs 0.84——**一致非劣 → 反转成立**。
2. **此前"E/P、低PS 槽位为负贡献"的组合层结论作废**：那是停牌 bug 污染下的观测。在正确语义下，E/P+PS 槽位提供了分散价值（两版 Jaccard 仍仅 0.34，选的确实是不同的票）。v3 相关矩阵说它们"冗余"，但冗余在组合层表现为**容错**——因子研究和组合构建对"冗余"的评价可以相反，这个教训记入方法论。
3. **新终审配置（模拟盘观察用）**：**五因子 0.40/0.20/0.15/0.10/0.10 + 行业≤3 + Top 5–8 + 双周调仓**。三因子版降级为鲁棒性参照（每次重验一起跑，监控两版差值是否稳定在噪声内）。
4. **不变的核心事实**：**两版 2025-26H1 均为负**（-0.61% / -0.11%），walk-forward 门对两个版本都未通过 → **不加仓立场不变**。P7 修复让历史更好看了，但没有改变"近期失效"这个决定性问题。
